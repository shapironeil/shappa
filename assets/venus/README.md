# Venus Dashboard Figma - Style Guide

Questa cartella contiene asset, icone, immagini e riferimenti di stile estratti dal progetto Figma "Venus Dashboard Builder 2021".

## Come usare
- Tutti i CSS e componenti UI della dashboard Shappa devono seguire palette, font, radius, spacing e stile Venus.
- Non modificare la logica o i contenuti delle pagine: solo restyling visivo.
- Gli asset SVG/PNG/JPG vanno inseriti qui e referenziati nei CSS/HTML.

## Elementi chiave
- Font: Inter, Roboto, Montserrat (come da Figma)
- Palette: blu, viola, grigi chiari, accenti giallo/verde/rosso
- Radius: 12px, 16px, 24px
- Spacing: 8px, 16px, 24px, 32px
- Icone: stile lineare, Material/Feather
- Cards, badge, sidebar, header, tabelle, modali

## Note
- Se servono nuovi asset, esportali da Figma e aggiungili qui.
- Aggiorna sempre questo README con le fonti e le varianti usate.
